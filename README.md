

# Abdullah Ahmed — Portfolio

My personal portfolio website showcasing my projects, skills, and experience as a Node.js Backend Developer.
 

---

🔗 Live Demo
 https://my-portfolio-git-main-abdullahahmeds-projects.vercel.app/

---

## 🛠 Built With
- **Framework:** Next.js
- **Styling:** CSS / Tailwind
- **Background:** HTML Canvas (particle network animation)
- **Hosting: Vercel
---

## 📌 Sections
- **Home** — intro, role, and social links
- **About** — brief bio
- **Skills** — tech stack organized by category
- **Experience** — work experience and courses
- **Projects** — highlighted personal projects
- **Contact** — email and social links

---

## 🚀 Run Locally
```bash
git clone https://github.com/AbdullahAhmed903/portfolio.git
cd portfolio
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000)
